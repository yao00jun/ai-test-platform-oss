# 源码与数据库结构分析

项目管理中的“五类输入与源码证据”面板接续现有需求文档、接口契约入口。后端源码、前端源码和 SQL 文件路径既可在新建/编辑项目时填写，也可在面板中保存；所有保存均使用原有项目版本与修订机制。未保存的路径可以作为本次分析的覆盖值，不会自动改写项目设置。

## 采集与版本

- 本地目录读取服务所在机器的绝对路径，不执行被分析项目的构建、包安装、脚本或注解处理器。私有仓库可以先在本地检出。
- HTTP(S) Git 地址不接受内嵌凭证、查询参数或片段。Git 在平台临时目录中获取对象，不 checkout、不递归子模块、不使用凭证助手或项目钩子。URL 默认读取 HEAD。
- 本地目录不填写版本时读取工作区；填写后端/前端 Git 版本时读取固定提交。提供后端对比基线而不提供目标版本时，目标为 HEAD。分支、标签、提交哈希及 `~`/`^` 祖先选择器均先解析为提交哈希。
- 基线后端文件与目标文件一起保存在同一不可变快照中，基线文件种类为 BASELINE。以后磁盘内容、分支或标签变化都不会改变该快照。
- SQL 输入为本地 `.sql` 文件或粘贴 DDL，可以同时提供。DDL 只用于解析结构，不在业务数据库执行。

默认每个快照最多 5,000 个文件、单文件 2 MiB、全部输入合计 64 MiB（包含基线及粘贴 DDL），目录深度最多 50 层。排除 `.git`、`node_modules`、`target`、`dist`、构建输出与隐藏文件，不跟随源码链接。文件须为 UTF-8；不支持的编码、二进制、超限和读取失败均有诊断。

可配置 `aitest.analysis.max-files`、`max-file-bytes`、`max-total-bytes`，以及 `aitest.analysis.git.max-repository-bytes`（默认 512 MiB）和 `timeout-seconds`（默认 120 秒）。`aitest.local-file-roots` 对本地来源执行已有允许目录限制。

## 解析结果

JavaParser 读取 Java 21 类/接口/record、方法签名和范围、Controller 映射、参数约束、业务分支、实体映射及调用信息。MyBatis 注解与 XML 均可读取；XML 外部实体与 DTD 网络访问被关闭。包含自定义实体的 Mapper 不以缺失实体后的 SQL 作为证据，而是返回诊断。

Vue/React 分析保留字面量页面属性、路由和表单限制的文件/行号。脚本字符串、注释和动态表达式不会被当成已渲染的定位器，父级条件也会传递给子节点。所有前端源码结果都标记为静态证据，仍需实际页面验证。

JSqlParser 提取 CREATE TABLE 列类型、ENUM、主外键、唯一键、约束和注释等定义。一个错误语句不会抹去前面已解析的表。ALTER、DROP、存储过程等未纳入结构演算的语句会明确报告“不支持”；这时表列表不能被当作完整最终 Schema。JSqlParser 的保留字与 MySQL 并非完全一致，例如未加引号的 `sample` 会被归类为不支持语句，反引号形式可解析。

READY 表示当前支持范围内采集/解析没有警告或错误；PARTIAL 必须同时查看诊断。二者都不表示业务正确性、实际 DOM 命中或动态调用解析的保证。分析只产生证据，不创建测试资产。

## 保存、取消与恢复

源码正文、分析结果及凭证字面量集合加密保存；公开结果与源码片段执行脱敏。每个文件有原始字节 SHA-256，快照另有清单哈希。片段每次最多 200 行、200,000 字符，读取受项目归属校验约束。

分析以 SOURCE_ANALYZE 持久化任务执行。最终发布与任务成功在一个短事务中完成；文件读取、解析、加密在事务外进行。取消后即使采集刚好完成，也不能发布文件快照或资产。

提交使用幂等键。同键同请求返回原 analysisId/jobId，同键不同请求返回 409。页面在当前浏览器会话中保存未确认提交的原输入；连接丢失或刷新后，“恢复源码分析提交”复用同一请求。项目切换后的晚到响应只更新原项目的恢复记录。手工路径草稿保留原 CAS 版本，冲突时由用户明确选择保留路径修改并使用最新版本。

当前分析入口、解析证据与历史查看已经实现；方法变更、调用影响面、定向回归及其执行证据绑定见 [源码变更与定向回归](source-impact.md)。源码驱动流水线、SQL/UI 校验及两级反馈见 [固定来源生成](source-grounding.md)。源码 RCA 继续由后续任务接入，不能仅凭完成采集就视为已具备全部源码智能能力。
