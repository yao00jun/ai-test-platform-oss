# 可配置项目看板

工作台的“项目看板”读取当前项目的 `DASHBOARD` 资产。没有保存布局时显示默认概览，点击“保存为我的布局”后即可编辑。多个布局可分别维护，当前显示选择保存在浏览器中，并按项目隔离。

在“编辑当前布局”中修改卡片标题、类型、尺寸、显示字段、可见性和记录数。拖动手柄或按上下方向键重新排序；添加、删除和修改在点击“保存修改”后生效。JSON 编辑与卡片编辑共用一份草稿，非法内容会明确报错。布局整体保存使用当前资产版本，遇到并发编辑时保留草稿并显示版本冲突。

| 卡片 | 实际数据来源 | 显示范围 |
| --- | --- | --- |
| 单项指标 | 当前功能用例数，或状态为 OPEN / IN_PROGRESS / REOPENED 的缺陷数 | 当前项目，排除删除记录 |
| 运行质量 | `QualityMetricsService` 的运行项、结果和实际耗时 | 最近 24 小时；通过率分母包含全部展开的运行项 |
| 测试资产 | 项目按资产类型汇总 | 当前存量 |
| 最近缺陷 | 实际缺陷及状态 | 按更新时间倒序，最多 10 条；点击名称打开原记录 |
| 最近运行 | 不可变运行记录 | 按创建时间倒序，最多 10 条；点击名称打开执行详情 |
| 模型效能 | EvalOps 的实际调用、使用量和人工评价 | 最近 24 小时；显示生成、执行和评价的独立样本数 |

无样本的通过率和正确率显示“暂无样本”，供应商未报告 Token 时显示“未报告”，缺少有效价格时显示“未计价”。金额按各次调用保存的价格版本估算。卡片不能保存手填统计值、HTML 或任意数据查询。

“AI 调优整个布局”沿用普通资产的多轮会话和原位替换机制。每轮读取当前已采纳版本，成功后保留布局资产 ID；失败、取消和版本冲突不会覆盖人工修改或其他布局。AI 结果同步到已打开的编辑器，未保存的手工草稿继续保留；用户可以比较后选择以新版本继续，或放弃草稿。全局反馈依旧使用显式选择、人工保护和原子采纳机制。

布局继续通过工作台的通用资产列表新建、删除、确认、查看历史、导入和导出。模板 `WORKBENCH / layout-json` 从 1.1.0 起包含版本化卡片示例。JSON 和 Markdown 导入导出保留卡片 ID、顺序、尺寸、字段、可见性和备注；HTML/PDF 用于文档导出。

每张卡片采用 `schemaVersion: aitest.dashboard-card/v1`，必需 `id/type/title`；布局内 ID 唯一，最多 50 张。类型包括 `metric/quality/assets/bugs/runs/evalops`，尺寸为 `small/wide/full`，`fields` 是该类型允许的非空、无重复字段数组。`bugs/runs` 可设置 1–10 的 `limit`。旧的 `metric: cases/openBugs` 模板仍可读取，保存时补齐版本和默认显示配置，不改其 ID 或顺序。
